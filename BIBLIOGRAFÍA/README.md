## 🎯 Propósito del Repositorio
Este directorio está destinado a almacenar y centralizar los **papers científicos, normativas y artículos de investigación** utilizados como soporte teórico y metodológico para el desarrollo de las entregas del proyecto de fin de curso (TA-PFC). Todas las referencias aquí incluidas se vinculan directamente con el archivo bibliográfico en formato BibTeX para el reporte en LaTeX.
